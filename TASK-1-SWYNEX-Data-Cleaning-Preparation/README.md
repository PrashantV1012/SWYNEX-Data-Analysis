Product Sales Data Cleaning
📌 Overview

This project focuses on cleaning and validating a raw Product Sales dataset using Microsoft Excel.

The objective was to identify data-quality issues and prepare the dataset for further analysis.

🧹 Data Cleaning Performed
-Identified missing values
-Checked for duplicate records
-Checked for duplicate Order IDs
-Validated data types
-Checked and standardized date fields
-Identified inconsistent values
-Checked invalid numeric values
-Validated Quantity, Unit Price, Discount, and Total Price
-Checked for incorrect delivery dates
-Standardized missing Promotion values as "No Promotion"
-Documented all cleaning steps in a cleaning log

📊 Dataset
Records: 1,500
Columns: 19
Tool: Microsoft Excel

🔎 Key Cleaning Results
370 missing Promotion values identified
0 duplicate Order IDs
0 duplicate records
0 invalid dates
0 invalid numeric values
0 delivery-date inconsistencies

The final dataset was cleaned, validated, and prepared for further analysis.
